## Artefatos do projeto

Liste os artefatos produzidos, com suas localizações e descrição do conteúdo.

* `/analise_exploratoria_state_of_data` - Pasta com o codigo da Analise Exploratoria de dados da base principal
* `/analise_exploratorias_perguntas_orientadas_a_dados` - Pasta com os codigos da Analise Exploratoria de dados para as perguntas orientadas a dados, principal e auxiliares.
* `/code_data_cleanest` - Pasta com os codigos da limpeza de dados de cada base de dados utilizada.
* `/modelos` - Pasta com os modelos de cada pergunta orientada a dados e sua explicaco.
